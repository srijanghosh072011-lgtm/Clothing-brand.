## Notes

### One code, permanently

`WELCOME10` is the same code as the welcome email, by your call. Two things
follow from that, and the copy above is written around both:

- **No deadline language.** No "ends Sunday", no countdown. The code doesn't
  expire, so any deadline would be a claim your customers can disprove in one
  click — and once they catch it, every real deadline you ever run gets
  ignored.
- **No per-campaign attribution.** Orders can't be traced to a send via the
  code. Use Shopify Email's own open/click stats plus the order timestamp
  instead. Less precise, but it works.

If you later want deadlines and attribution back, the change is: generate a
fresh code per campaign (`NOCT-OCT`, `NOCT-NOV`) with a 7-day expiry set on the
discount itself, and swap `WELCOME10` in this template for the new code each
send. Roughly two minutes per campaign. Everything else stays as-is.

### Don't make it monthly-on-a-date

You said "every month or so" — keep the *or so*. A discount that lands on the
1st of every month teaches your list to wait for the 1st, and you end up
discounting people who'd have paid full price anyway. **5–6 weeks, varied, is
the pattern that works.** It stays a reason to open without becoming a schedule
people plan around.

This matters more with a permanent code than it would with expiring ones: the
code is always live, so cadence is the only thing creating any sense of
occasion.

### Suppression

Exclude anyone who ordered in the last 14 days. Nobody wants a discount code
three days after paying full price for the same thing.
